# Cacao

Cacao es una app de finanzas personales gamificada para iOS. Automatiza el
tracking de gastos leyendo notificaciones bancarias por correo (OAuth) y, en
v2+, usará mecánicas de juego (moneda, recompensas, un "Patrimonio" tipo
Township) para reforzar buenos hábitos financieros.

**v1 es 100% financiero: cero UI y cero lógica de juego.** Todo lo de
gamificación queda documentado como placeholder para v2.

## Estado actual
